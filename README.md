# Live Translation 实时翻译系统

一个专为基督教礼拜场景设计的实时语音转文字翻译系统，支持中英文双语显示和同步滚动。

## 产品概述

Live Translation 系统为海宁夏沙基督教会礼拜提供实时语音转文字和翻译服务。系统通过高性能的语音识别技术，将现场讲道内容实时转换为文字，并提供中英文双语显示，方便会众更好地理解和参与礼拜。

## 核心功能

- 🎤 **实时语音识别** - 基于OpenAI Whisper模型的高精度语音转文字
- 🔄 **双语翻译** - 支持中英文实时翻译和同步显示
- 📱 **响应式界面** - 适配各种设备屏幕，支持移动端和桌面端
- 🌐 **WebSocket通信** - 低延迟实时数据传输
- 🎯 **智能滚动** - 自动跟随翻译内容滚动，提供良好阅读体验
- ⚡ **GPU加速** - 支持TensorRT加速，提升识别性能

## 技术栈

### 前端
- **Nuxt 3** - Vue.js全栈框架
- **Vue 3** - 渐进式JavaScript框架
- **Pinia** - Vue状态管理库
- **WebSocket** - 实时通信协议
- **OpenCC** - 中文字符转换库
- **Font Awesome** - 图标库

### 后端
- **[WhisperLive](https://github.com/collabora/WhisperLive)** - 基于Collabora开源项目进行了破坏性改动，适配本项目的特定需求
- **OpenAI Whisper** - 语音识别模型
- **TensorRT** - GPU加速推理（可选）
- **Python** - 后端开发语言

## 快速开始

### 环境要求
- Python 3.8+
- Node.js 16+
- CUDA支持（GPU加速）
- Conda环境管理

### 安装运行（作者仅个人使用，未进行部署测试，如有问题可提Issue）

1. **克隆项目**
```bash
git clone <repository-url>
cd livetrans
```

2. **启动服务**
```bash
# 使用启动脚本（推荐）
./start.sh

# 或手动启动
python main.py
```

3. **访问应用**
- 前端界面：http://localhost:3000
- 语音识别服务：ws://localhost:9090
